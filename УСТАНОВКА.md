# Установка на другую машину

```bash
./install.sh
```

Скрипт заведёт сертификат для подписи, соберёт программу, положит её в `/Applications`
и запустит. После этого — один ручной шаг:

**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включить Switcher.**

Без этого доступа программа видна в строке меню, но бессильна: ни прочитать выделение,
ни впечатать исправление она не может. Выдать его нужно ровно один раз.

## Что нужно на машине

- macOS 13 и новее.
- Xcode Command Line Tools (`xcode-select --install`) — для сборки из исходников.
  Если их нет, `install.sh` поставит вложенный готовый `Switcher.app` и подпишет его
  здешним сертификатом. Собирать из исходников лучше: бандл собран под эту архитектуру.
- Включённые в системе раскладки, между которыми нужно переключаться. Таблица раскладок
  не зашита в программу, она читается из системы — работает любая пара, не только ЙЦУКЕН↔QWERTY.

## Почему сертификат, а не ad-hoc

macOS опознаёт программу по требованию из подписи. У ad-hoc подписи это «хэш файла равен
такому-то» — любая пересборка выглядит новой программой, и выданный Универсальный доступ
слетает. У сертификата требование привязано к самому сертификату, поэтому доступ выдаётся
один раз и переживает пересборки. Сертификат самоподписанный, живёт в связке ключей
и создаётся установщиком на 10 лет.

## Перенос личного словаря

Выученные слова и настройки лежат в `~/Library/Application Support/switcher/`:

| файл | что внутри |
|---|---|
| `learned.json` | слова, выученные вашими ручными перебивками — имена, жаргон, названия |
| `log.json` | журнал последних починок |
| `trace.log` | пошаговая запись работы, нужна только при разборе «ничего не происходит» |

В архив они намеренно не входят: это личные данные, а архив можно передать кому угодно.
Чтобы перенести словарь на новую машину — скопируйте туда `learned.json` **до** первого
запуска (программа читает его при старте и перезаписывает своим состоянием при первом же
новом уроке).

Настройки хранятся в `UserDefaults` домена `local.switcher`. Перенести их так:

```bash
# на старой машине
defaults export local.switcher ~/Desktop/switcher-settings.plist
# на новой
defaults import local.switcher ~/Desktop/switcher-settings.plist
```

## Если что-то не работает

Первым делом — журнал запуска: `~/Library/Application Support/switcher/startup.log`.
Строки `доступ выдан` и `перехват готов` должны быть `true`. Дальше — `trace.log`:
в нём видно каждое разобранное слово и причину, по которой его не тронули.
